## PART-2
In Part 2, an external CSS stylesheet (style.css) was added and linked 
to all 5 HTML pages to style the website to look like a South African 
supermarket such as Checkers and Pick n Pay.

### What was added in Part 2:
- Created style.css and linked it to all HTML pages
- Added Google Fonts (Barlow Condensed and Nunito Sans)
- Styled the header with a red gradient and pill-shaped nav links
- Added red banner tab styling to all section headings
- Added product card hover effects with red accent bars
- Styled the delivery form with red focus rings and a CTA button
- Made the site responsive for mobile, tablet and large screens
- Fixed the broken product category list on the homepage
